## Overall Impression

Bench reads as a serious mathematical instrument. Display ladder closes the readability gap on Runge results, persistent warning row never lets pedagogy hide, keyboard surface gives the persona room to iterate. Remaining items are details, not priorities.

## What's Working

1. Display digits ladder + near-zero filtering. Runge polynomial drops to 6 readable terms at 12 digits with a visible "5 near-zero terms hidden" note. Full round-trips to the 50-digit truth.
2. Persistent warning row sits above the result tabs and routes to Notes.
3. Method-selector role retune. TEACH/VERIFY/PLOT/TARGET teach four jobs, Barycentric (PLOT) primary-tinted as the unique graph source.
4. Three-voice typography under load. Methods tab with Lagrange basis polynomials, divided-difference, Neville tables: all numerics tabular monospace, all section labels font-label, all descriptions body.

## Priority Issues

**[P2] Theme toggle violates WCAG 2.5.3 (Label in Name).**
Why it matters: Lighthouse flagged this as serious. Button shows "System" but aria-label is "Switch to light mode". Voice-control users saying "Click System" cannot trigger the button because the accessible name does not contain "System".
Fix: build the accessible name from the current state ("System theme, switch to light mode") so the visible label is a substring.
Suggested command: /impeccable harden.

**[P2] PolynomialCard formatPoly is correct only for the expanded form.**
Why it matters: formatPoly parses top-level terms split by +/-. Lagrange summation, factored "(x - 2)(x - 5)", and Newton nested forms can be incorrectly clipped at low digit budgets when an inner near-zero coefficient hits the threshold.
Fix: apply formatPoly only to expanded; for factored / Lagrange / Newton, use a regex-based numeric replacement that does not split structure, or pass through at "Full".
Suggested command: /impeccable harden.

**[P3] Empty-state column headers read as garbled letters to AT.**
Why it matters: snapshot shows StaticText "I"/"X"/"I"/"Y"/"I" because <sub> markup adjacent to a single letter splits oddly on the a11y tree. Visual UI reads i, x_i, y_i correctly, AT users hear "I, X, I, Y, I".
Fix: wrap each column-header text node in an explicit aria-label ("row index", "x sub i", "y sub i") for PointsInput, NodesTable, EvaluationTable.
Suggested command: /impeccable harden.

**[P3] Display digits control rendered twice in the DOM.**
Why it matters: ResultsPanel mounts one DisplayDigitsControl in the desktop area and another (md:hidden) in the mobile area. Eight radios in DOM, four visible. Voice-control users may hit the wrong instance; query selectors are brittle.
Fix: render once and rely on flex ordering or a useMediaQuery hook to mount only the visible one.
Suggested command: /impeccable harden.

**[P3] No <meta name="description"> on the document.**
Why it matters: Lighthouse SEO 60 is mostly this. Cheap one-line fix; helps browser-tab and shared-link previews if the tool is ever hosted publicly.
Fix: add <meta name="description" content="A scientific workbench for polynomial interpolation..."> to frontend/index.html.
Suggested command: /impeccable polish.

## Minor Observations

- MethodSelector role tags use font-label uppercase. At their pill size with primary tint on Barycentric this reads slightly aggressive. Consider lowercase with the same letterspacing.
- SummaryCard MODE cell mixes body voice ("Numeric"/"Exact") with monospace numerics in the other three cells. Visual rhythm reads as "three numbers and a word".
- Bundle is 975 kB unminified (290 kB gzipped). Code-splitting recharts and katex would knock that down materially.
- KaTeX font set is ~750 kB across dist; for English-only formula output, a font subset could halve cold-load size.
- EvaluationTable |Error| column header uses the literal pipe character; AT may read as "vertical bar Error vertical bar". An aria-label of "absolute error" on the <th> would help.
- ExamplesPanel Compute button title "Backend offline" doesn't show on disabled buttons in many browsers. Inline body text under the example card title would help.
- Footer copy still developer-shaped. Consider "Computed by SymPy and mpmath at your chosen precision."
- DESIGN.md is missing the new --success token; if the design doc is a contract, the new token should be declared there too.
